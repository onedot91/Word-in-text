# 속삭이는 칠판

초등학교 3학년 수준의 어휘력 향상을 목표로 만든 선택형 텍스트 어드벤처입니다. 플레이어는 고마가 되어 친구들과 함께 숲속 학교의 이상한 칠판 문장을 조사하고, 낱말의 뜻과 쓰임을 이해해 단어 씨앗을 되찾습니다.

## 주요 특징

- 초3 수준의 생각, 표현, 감정, 감각, 상태, 논리 어휘 33개 수록
- 단순 뜻 맞히기가 아니라 장면 해결에 낱말을 사용하는 선택지 구조
- 선택 결과가 점수, 단서, 친구 신뢰도, 배운 낱말, 복습 낱말에 반영
- 엔딩에서 모험 기록과 학습 피드백 제공

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
